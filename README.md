# 🐢🐰 龜兔賽跑 (SEL改編版) — 兒童互動翻頁繪本

> **適讀對象**：國小一至四年級學童、親職家庭教育、班級情緒教育課堂  
> **核心主題**：社會情緒學習 (Social-Emotional Learning, SEL) — 情緒調節、正向自我對話、同理心與道歉修復  
> **技術架構**：純前端靜態技術 (HTML5 + CSS3 + Vanilla JS + Web Audio API + Web Speech API)，零後端依賴、無須打包編譯，完全支援 GitHub Pages！

---

## 🌟 繪本特色與設計亮點

1. 📖 **左右對開經典童書排版**：
   - **左頁**：高畫質大插圖（圓角質感相框、微陰影，不遮擋插畫）。
   - **右頁**：大字級故事內文（24~28px）、寬闊行距（2.3）、標準注音拼音、SEL 小活動卡片。
   - 完全告別擁擠雜亂與內置滾動條，視覺乾淨通透。
2. 🔤 **國小注音 (Bopomofo) 一鍵開關**：
   - 內文採用標準 HTML `<ruby>` 精準標註台灣教育部審定注音與聲調。
   - 設有頂部按鈕可隨時切換注音顯示／隱藏。
3. 🔊 **國語語音朗讀 (TTS)**：
   - 點擊「念給我聽」自動以親切自然的語音朗讀該頁內容，朗讀時伴隨溫暖發光高亮。
4. 🎵 **Web Audio 原生翻頁紙張音效**：
   - 翻頁時由瀏覽器原生合成紙張摩擦聲（沙沙聲），零延遲且不需額外載入音檔。
5. 🎈 **每頁專屬 SEL 互動小活動**：
   - **第一幕（自我管理）**：跟著小烏龜「4秒吸氣、4秒吐氣」呼吸球互動。
   - **第二幕（正向對話）**：點擊烏龜彈出「一步一步來，我做得到！」星星動態金句。
   - **第三幕（同理抉擇）**：終點在前 vs 扶起受傷白兔情境二選一與即時反思。
   - **第四幕（修復道歉）**：點擊雙動物和好 High-Five 友誼彩帶噴發。
   - **第五幕（森林微影院）**：內嵌 40 秒完整 3D 動畫《龜兔賽跑》影片，並附「SEL 情緒小勇士」榮譽勳章領取卡！
6. 📱 **完整響應式支援**：
   - 電腦與平板橫向呈現經典大繪本對開；手機直式自動無縫調整為單頁卡片閱讀。

## 🌐 未來佈署到 GitHub Pages 步驟 (準備好時再執行)

本專案所有資源皆採用相對路徑 (`./assets/...`)：
1. 在 GitHub 建立一個新 Repository（如 `sel-story-book`）。
2. 在本資料夾執行：
   ```bash
   git init
   git add .
   git commit -m "feat: 龜兔賽跑 SEL改編版繪本"
   git branch -M main
   git remote add origin https://github.com/<您的帳號>/sel-story-book.git
   git push -u origin main
   ```
3. 前往 GitHub 的 **Settings** -> **Pages**，將 Branch 設定為 `main` / `root` 並存檔，即可免費發佈上線。
